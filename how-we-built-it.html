01
START HERE, ALWAYS

START WITH
THE BRAND

Nothing gets made until the brand exists. We locked three things first: the idea (a parody as-seen-on-TV product, sold with a straight face), the voice (sincere, premium, faintly unhinged — "get rockin'"), and the system that every later step would inherit.

Get this right and the rest of the build practically writes itself, because every decision after it has a rule to follow.

THE HUMAN BROUGHT
  • the idea & the taste
  • what's funny, what's not
  • the final yes / no
CLAUDE BROUGHT
  • turned it into a documented system
  • pressure-tested the concept
  • kept everything consistent
02
SAY IT OUT LOUD

WRITE THE WORDS

With the voice locked, the copy comes fast: the product name, taglines, the four feature pillars (REAL ROCKS · MAX POWER · EASY GRIP · BUILT TO LAST), the FAQ, the absurd-but-sincere sell. The trick is generating a lot, then keeping only what's funniest and most on-voice.

BE A FASHION ROCKSTAR! Get rockin'!
draft at volumecut to the bestone locked voice
03
MAKE IT A LOOK

BUILD THE
VISUAL KIT

A palette of eight colours, four typefaces with clear jobs, and a set of components — thick black borders, hard offset shadows, halftone dots, starbursts. Define it once as a reusable kit and the whole site feels like one thing instead of ten.

ANTON — the big shouts BUNGEE — the chunky labels Permanent Marker — the human bits Poppins — the things you actually read
04
FILL THE WORLD

GENERATE
THE ASSETS

Every image and video was made in Higgsfield, connected straight into the workspace through MCP. Photoreal stills came from Nano Banana; motion came from Kling and Seedance. Claude wrote each prompt to one locked photoreal recipe; the human generated and curated the keepers.

Same pipeline for the game art: real rock photos, cut to clean transparent cut-outs, dropped straight into play.

Nano Banana — stillsKling / Seedance — videoMCP — right in the workflowhuman curates
05
ASSEMBLE IT

BUILD
THE SITE

Claude wrote the site as a single self-contained HTML file — structure, styling and behaviour in one place, every asset wired in. Audio-reactive hero, parallax bands, a rock-sticker toy, all responsive down to a phone. No framework. No build step. Just a file that runs anywhere.

HTML · CSS · JSno frameworkone fileruns anywhere
06
GIVE IT EARS

ADD
THE SOUND

A real stone-impact recording (from Epidemic Sound) was sliced into one-shots, embedded right inside the page as data, and played through the Web Audio API — pitch-shifted and stacked on the fly so the same rock never sounds twice. A small thing that makes everything feel real.

real rock samplesWeb Audio APIno repeats
07
HIDE A TOY INSIDE

BUILD
A GAME

Then the fun part: an arcade easter egg built in the exact same brand language. ROCKALANCHE — a bubble-shooter where you fire real rocks at a wall of real rocks, match three to crumble them, and the wall creeps down on you. Same palette, same real rocks, same real rock sounds.

aim & bank shotsmatch-3 crumbleone-handedon-brand
08
PUT IT ONLINE

SHIP IT

Because it's all static files, shipping is trivial: the files live in a GitHub repo, Vercel watches it, and every commit is live in about twenty seconds. The game is just another file in the same folder — link to it and it plays. No servers to run, nothing to maintain.

GitHubVercelstatic · instantlive in ~20s
THE DIVISION OF LABOUR

HUMAN × CLAUDE

The method works because each side does what it's best at. The human owns the vision and the taste; Claude owns the structure, the volume, and the execution — and the loop between them is fast.

HUMAN
  • the idea and the standards
  • generating & picking assets
  • creative direction & final calls
  • "make it funnier / weirder / cleaner"
CLAUDE
  • the brand system & all the copy
  • every prompt for the assets
  • the full site & game in code
  • fast rebuilds on each round of notes
